# Hema P — AI/ML Internship Portfolio

A responsive, dark-modern portfolio website made with plain HTML and CSS. It includes a downloadable resume in `assets/resume.pdf`.

## Publish on GitHub Pages

1. Download and unzip `hema_ai_ml_portfolio.zip`.
2. Sign in to GitHub and open https://github.com/new
3. Create a repository. For example, name it `hema-portfolio`. A public repository is easiest for a public portfolio.
4. Open the new repository and choose **Add file → Upload files**.
5. Upload `index.html` and the `assets` folder (including `resume.pdf`). Keep the folder structure as shown:
   - `index.html`
   - `assets/resume.pdf`
6. Click **Commit changes**.
7. Open the repository's **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/(root)`, then click **Save**.
10. Wait a few minutes. The published website URL will appear in the Pages section. For a repository named `hema-portfolio`, it is usually:
    `https://Hema1207-r.github.io/hema-portfolio/`
